# Per-Touch Quick Checklist

Print this or keep it pinned next to your phone/screen. Full detail lives in `call-handling-sop.md` and `lead-note-template.md` — this is the fast version for mid-call use.

**Before:** [ ] Lead record open  [ ] Read last SITUATION + NEXT STEP

**Ask (whatever you don't already have):**
- [ ] Motivation
- [ ] Timeline
- [ ] Condition
- [ ] Price expectation
- [ ] Decision maker / blockers

**After — every touch, no exceptions:**
- [ ] Note logged (SITUATION + NEXT STEP minimum)
- [ ] Status/stage updated
- [ ] Follow-up task/reminder set to match NEXT STEP date

**End of day:** [ ] Every lead touched today has a dated next step logged
