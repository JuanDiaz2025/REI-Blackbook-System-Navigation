# Per-Touch Quick Checklist (REI BlackBook)

Print this or keep it pinned next to your phone/screen. Full detail lives in `call-handling-sop.md` and `lead-note-template.md` — this is the fast version for mid-call use.

**Before:** [ ] Contact record open  [ ] Read last `++ Situation` + `++ Next Step` in Notes tab

**Ask (whatever you don't already have):**
- [ ] Motivation
- [ ] Timeline
- [ ] Condition
- [ ] Price expectation
- [ ] Decision maker / blockers

**After — every touch, no exceptions:**
- [ ] Notes tab: `CALL SUMMARY` logged (`++ Situation` + `++ Next Step` minimum)
- [ ] Temperature badge updated (Cold/Warm/Hot) if it changed
- [ ] Contact Type / Tag(s) updated if the call revealed new info
- [ ] Tasks tab: follow-up task set to match `++ Next Step` date

**End of day:** [ ] Every contact touched today has a dated Next Step logged + a matching Task
