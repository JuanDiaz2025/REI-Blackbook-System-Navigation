# Lead Note Template (use on every touch)

Paste this into the Notes section of the lead record on **every** call, text, email, or voicemail — inbound or outbound. Keep it short; the goal is that the next person (or you, in 3 weeks) can read the last note and instantly know where things stand and what to do next.

```
[MM/DD/YYYY HH:MM] – [Touch Type] – [Outcome]
SITUATION: <one line: what's the current state of this deal/lead>
DISCUSSED: <key points raised this touch>
OBJECTION/CONCERN: <if any, else "none">
NEXT STEP: <specific action> — Due: <date> — Owner: <you/them>
STATUS: <lead stage / temperature>
```

**Touch Type:** Call In / Call Out / Voicemail / Text / Email
**Outcome:** Connected / No Answer / Left VM / Callback Requested / Not Interested / Appointment Set / etc.

## Filled-out example

```
[07/31/2026 14:12] – Call Out – Connected
SITUATION: Seller inherited property, still deciding between listing vs. cash sale.
DISCUSSED: Walked through timeline (needs to close by Sept), condition (roof issue), price expectation ($180k).
OBJECTION/CONCERN: Wants to compare to a realtor's opinion first.
NEXT STEP: Send cash offer range by email today — Due: 07/31/2026 — Owner: me. Follow up call — Due: 08/04/2026 — Owner: me.
STATUS: Warm — comparing options
```

## Rules of thumb

1. **One note per touch, no exceptions.** If nothing changed, still log the touch ("No Answer, left VM, will retry Thu").
2. **SITUATION is not history** — it's the *current* snapshot. Overwrite your mental model of "where this deal is" every time, don't just append.
3. **NEXT STEP must be concrete and dated.** "Follow up" is not a next step. "Call back Thu 8/6 to confirm inspection date" is.
4. **STATUS drives your pipeline view** — keep it current so a glance at the pipeline tells you who's hot without opening every record.
5. If you're mid-call and can't type the full template, jot SITUATION + NEXT STEP only, then backfill DISCUSSED after the call from memory/recording — those two fields are the non-negotiable minimum.
