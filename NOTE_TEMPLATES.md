# REI BlackBook Note Templates

House-style templates for drafting notes on contact records. Use the CALL SUMMARY template for calls; use the TEXT NOTE template for text-only touches.

## CALL SUMMARY

```
CALL SUMMARY - <Month DD, YYYY>
[*** STATUS FLAG *** — optional, e.g. NEW LEAD / APPT BOOKED / UNDER CONTRACT / OPT-OUT / NOT A SELLER]
++ Contact Result: <inbound/outbound + who handled + duration> - <one-line outcome>
++ Property: <address / city>   (or "no address on file")
++ Contact/Seller: <name, phone, email, source>
++ Motivation: <why selling / situation>
++ Condition: <property condition, repairs>
++ Pricing: <asking / our offer / comps / gap>
++ Timeline: <how soon they want to sell/close>
++ Appointment: <date + time + who's inspecting>   (when one is set)
++ Next Step: <the concrete follow-up action>
++ Lead Temperature: <HOT / WARM / COLD / DEAD / N/A>
++ Texts: <any texts/emails sent or to send>
```

## TEXT NOTE

```
TEXT NOTE – [Month DD, YYYY]
++Call: [outcome, 1-3 words].
++Texts: [Outbound/Inbound, you do not have to specify the sequence of outbound or inbound text message, just identify the most recent text touch and identify if it is an outbound/inbound] – [summary of message sent/received].
++Next Step: [Action instruction in plain language]
++ Lead Temperature: [HOT/WARM/COLD/DEAD] — [short repeat of action].
```
